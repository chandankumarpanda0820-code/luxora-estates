# LUXORA ESTATES

### Discover Exceptional Living.

LUXORA ESTATES is a premium luxury real estate website designed to showcase exceptional properties and deliver an elegant browsing experience. It features a sophisticated dark theme with champagne-gold accents and a responsive layout.

## Live Demo

https://chandankumarpanda0820-code.github.io/luxora-estates/

## Preview

A modern, luxury-inspired real estate website featuring premium property listings, elegant layouts and interactive elements.

## Features

- Premium luxury-inspired UI design
- Fully responsive layout
- Smooth single-page navigation
- Featured property listings
- Property category filters
- Property details modal
- About Us section
- Services showcase
- Why Choose Us section
- Client testimonials section
- Contact and enquiry form
- WhatsApp enquiry integration
- Click-to-call functionality
- Social media links
- Dynamic copyright year

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- Google Fonts

## Getting Started

1. Clone this repository:

```bash
git clone https://github.com/chandankumarpanda0820-code/luxora-estates.git
```

2. Open the project folder:

```bash
cd luxora-estates
```

3. Open `index.html` in your browser.

No additional package installation is required.
